A small collection of some of my most recent, or at least most impactful works. This is by far not a list of everything that I've done professionally, most of which is closed source and unfortunately protected by NDAs, but if you want to have a better idea of everything I've done publically you can check out all my GitHub repositories.

web applications

The concept of a web application these days is, sadly, of a full-fledged desktop application that runs in your browser, with millions of lines of obfuscated Javascript, and sometimes other languages compiled to WebAssembly and running straight on your browser. The web applications that I have developed are nothing like that, never will be, and are basically what you would expect a web application to be back in 2010.

PickLE

A web application for managing and using electronic component pick lists with a theming engine that allows it to look great on modern platforms while still being compatible with browsers from the nineties.

Litter Box

A simple solution to upload and share files extremely quickly with strangers on the internet. Supports uploading and sharing with weirdos that still use 90s computers.

PHP Photo Viewer

A super lightweight and retro-friendly PHP 5.4 photo viewer library and website. Perfect for a digicam photo gallery.

libraries

Some of the libraries that I have created to help myself and other developers when writing solutions.

Fantastique

An unopinionated, and labour intensive, static website generator for PHP. Allowing users to have all the flexibility they need to create any kind of static web site as if it were a classic PHP project.

PickLE

An application and a parsing library to create an electronic component pick list file format designed to be human-readable and completely usable in its own plain-text form.

ascii-image

A Ruby gem to convert any image into a lovely, colored, blocky, ASCII representation for showing off on your terminal.

PHP Photo Viewer

A super lightweight and retro-friendly PHP 5.4 photo viewer library and website. Perfect for a digicam photo gallery.

applications

Remember when we had applications that ran locally on our computers and didn't require a constant internet connection and spied on you? I do and I have made quite a bunch of them.

Rodent

A modern, native, graphical Gopher client for new and old computers. Bringing you the joys of glorious plain text in a modern graphical interface.
